# Portable-AI-edictor
随身 AI 调用工具 这是一款基于 API 接入的 Android 端 AI 工具，设计初衷是让用户能够以更简便、更本地化的方式调用自己的 AI 服务。 /   Pocket AI   Pocket AI is an Android-native tool for calling AI services through your own API keys. It's built for developers and tinkerers who want a lightweight, local-first experience without relying on bloated third-party apps.
